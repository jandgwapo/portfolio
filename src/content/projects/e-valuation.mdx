title: E-Valuation

<section class="case-study-block">
  <h2>The Project</h2>
  <div class="case-study-block-body">
    <p>
      E-Valuation is a cross-platform web and mobile Latin honor evaluation system created for our capstone project. It
      brings the evaluation workflow into one focused experience that can be used across web and app environments.
    </p>
  </div>
</section>

<section class="case-study-block">
  <h2>The Build</h2>
  <div class="case-study-block-body">
    <p>
      The system is built with Flutter to support a shared cross-platform experience, with Supabase providing the
      database and backend services. The goal was to keep the workflow clear, practical, and accessible wherever the
      evaluation needs to happen.
    </p>
  </div>
</section>

<section class="case-study-block">
  <h2>Outcome</h2>
  <div class="case-study-block-body">
    <ul>
      <li>A web and mobile experience for Latin honor evaluation.</li>
      <li>One cross-platform codebase built with Flutter.</li>
      <li>Supabase-backed data and application services.</li>
    </ul>
  </div>
</section>
