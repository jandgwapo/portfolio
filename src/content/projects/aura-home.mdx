<section class="case-study-block">
  <h2>The Project</h2>
  <div class="case-study-block-body">
    <p>
      Aura Home is a live home and lifestyle web experience built for browsing across desktop, tablet, and mobile. The
      goal was to give the brand a clearer digital presence while making it easy for visitors to discover the right
      information and move toward the next action.
    </p>
    <p>
      The interface was shaped around a clean, responsive presentation for a home-focused brand. Spacing, typography,
      and reusable sections work together to create a calmer browsing experience across screen sizes.
    </p>
    <p>
      I also paid attention to how the experience changes between desktop and mobile. The layout keeps its hierarchy as
      the viewport narrows, so visitors can move through the page without losing context.
    </p>
  </div>
</section>

<section class="case-study-block">
  <h2>The Build</h2>
  <div class="case-study-block-body">
    <p>
      I worked on the web development and responsive UI, using PHP and Laravel for the application foundation, Tailwind
      CSS for the interface styling, MySQL for the data layer, and GSAP for purposeful motion.
    </p>
    <p>
      Tailwind CSS made it easier to keep spacing, responsive behavior, and component patterns consistent. Laravel
      provided the structure for the application, while GSAP added movement to key moments without turning the interface
      into a distraction.
    </p>
  </div>
</section>
